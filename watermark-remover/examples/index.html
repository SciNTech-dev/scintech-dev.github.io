How these are made

One clean source: an illustration of a bear on a train, 1024 × 1024 pixels, used at its native size. For each case a generated mark is stamped on it with a fixed random seed, then saved through the same JPEG step as the clean copy, so the score measures the mark and not the compression. Illustrations have flat colour and clean lines, which may make them easier than photographs; a photographic set comes later.

Each input goes through the app’s own removal code (v0.2.4, commit 81c6725537c7), run on a computer rather than a phone, one picture at a time, with the classical fill the app uses when its on-device AI fill is not available. Nothing is tuned per example.

Scores are PSNR over the whole picture against the true clean image, computed on the lossless results; the images shown here are compressed for the web. A declined case is scored as the unchanged input. Running the engine twice gave byte-identical results.
