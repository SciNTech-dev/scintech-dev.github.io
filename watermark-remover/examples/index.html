Examples

Scored against the truth.

Every example here is synthetic: a picture with a generated mark stamped on it, so the true clean image exists and each result is scored against it. No number on this page comes from a real photo.

Three ways to remove a mark

Have the watermark file? Open it and remove the mark from any photo.

In the Workbench, step 2, choose Open a watermark file and pick the mark's file; the app finds the mark on each photo and removes it. On 42 synthetic pictures (21 kinds of mark, two pictures each): 41 ended closer to the true picture, 1 further, 0 declined; mean change +14.47 dB.

It works when the file matches how the mark was applied: a mark the app learned and saved, or your own exported mark file. A plain logo at a guessed opacity is not that: in a separate test with the logo at 50 % opacity, the pictures ended further from the truth on average (−2.01 dB over 84 pictures).

No file? Learn it from 5–8 photos.

Give the app 5–8 photos with the same mark; it learns the mark, you save it, and it becomes a watermark file for new photos. Learned from 8 photos and applied to the same pictures: 33 of 42 closer, 1 further, 8 declined; mean +4.77 dB.

Quick: two photos.

Two photos with the same mark, cleaned in one go: 34 of 42 closer, 0 further, 8 declined; mean +3.07 dB. Here the learn sees the very photos it cleans.

How these are made

Each case stamps one generated mark, with a fixed random seed, on two illustrations of a bear (1024 × 1024 pixels), then saves them through the same JPEG step as the clean copies. The watermark file is the mark that was stamped, written in the app's own watermark-file format (a PNG the app exports and opens). The app's own code (v0.2.8, commit 27002d8cc896) opens the file through the same function as the Open a watermark file button, finds the mark on each picture and removes it. It runs on a computer, with the classical fill the app uses when its on-device AI fill is not available. Nothing is tuned per example.

The saved mark is learned from 8 other photos (a research image set, DIV2K, whose licence allows research use only, so they are not shown), saved, loaded back and applied to the bears. The two-photo results are learned from the two bears themselves. In every test the mark sits in the same place on each photo; a moved or resized mark was not measured.

Scores are PSNR over the whole picture against the true clean image, computed on the lossless results; the images are compressed for the web. A declined result is scored as the unchanged input. Running the engine twice gave byte-identical results.

Scripts scripts/site_examples_file.py, site_examples_template.py, site_examples.py; all numbers in gallery.json.
