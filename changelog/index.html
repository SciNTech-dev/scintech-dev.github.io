Watermark Remover

Watermark Remover releases

On Google Play as Watermark Remover (Offline) since 2026-10-15; releases up to 0.2.12 went to a closed test only. Current release: 0.8.0 (build 91). Notes are the app’s release notes as written for Google Play, unedited. Dates are the release tags’ dates (0.5.0: its version bump); build 47 shipped the 0.2.0 text again.

0.8.0

build 91 · 2026-11-27

New: repeating (tiled) watermarks are learned more accurately from several photos.
New: share a before/after comparison in one tap.
New: open .npz watermark template files.
Settings: automatic reports are grouped into clear on/off categories.
Fixed: memory and reliability issues with large photos.

0.7.6

build 90 · 2026-11-10

Fixed: saving photos failed on Android 9 and older.

0.7.5

build 89 · 2026-11-06

Easy mode now tells you plainly when a picked file is a video: videos can't be processed, so add photos instead.

0.7.4

build 88 · 2026-11-06

Imported watermark files in Easy mode are now placed exactly, fixing faint outlines left around the mark, especially on high-resolution photos.

0.7.3

build 87 · 2026-11-05

Fixes a crash that could happen when leaving the app in the middle of a large multi-photo job and coming back to it (saved state was too large for the system). No changes to the watermark removal itself.

0.7.2

build 86 · 2026-11-04

Easy mode now handles a single photo: it goes straight to the one-photo AI and shows the result, with "Not perfect" to touch it up by hand. Skip and "Not a pair" now keep both pictures in the job as watermarked photos, so nothing is lost and the pair is not suggested again.

0.7.1

build 85 · 2026-11-03

Same-scene bursts now fall back to the one-photo AI instead of stopping, and the results screen says honestly when each picture was processed on its own. Repeating marks with staggered copies, such as two-tone signatures, now lock onto the right grid and come out cleaner. Also new since 0.6.1: "Our apps" in the menu, built in and fully offline.

0.7.0

build 84 · 2026-11-02

New: "Our apps" in the menu. See the other apps made by SciNTech, right inside the app. The list is built in and works fully offline.

0.6.1

build 83 · 2026-11-01

Easy mode now falls back to the one-photo AI when it cannot learn the watermark from your photos, instead of stopping. In Advanced mode, "Compare with one-photo AI" shows both results side by side so you can keep the better one for each photo.

Also in this build, not in the Play notes: reports now carry ANR (app not responding) and stability diagnostics, and the one-photo model’s memory is held under a session lease.

0.6.0

2026-10

One-photo watermark removal (neural, on-device); works for 1-2 photos where the multi-photo learner refuses.

0.5.4

2026-10-24

Learning a watermark from several photos now uses all of them on phones with less memory, instead of quietly dropping some. If your photos are near-identical shots of the same scene, the app now tells you to add photos with different backgrounds instead of producing a damaged result.

0.5.3

2026-10-23

Quick Remove now recognizes a repeating (tiled) watermark and suggests adding a few more photos with the same mark for a clean result. Brush removal on large photos no longer runs out of memory. Fixed Autopilot rejecting some photos as unreadable.

0.5.2

2026-10-20

Fixed an out-of-memory crash on phones with less RAM: the AI fill now uses far less memory and is shared between screens. When you add a clean original alongside several watermarked photos, it is now always used to learn the watermark.

0.5.1

2026-10-18

Fixed a crash that could happen when cleaning started in the background. Large or unusual photos that ran out of memory or could not be decoded now show a clearer message. Photos of different sizes that share a corner watermark can be cleaned together. Removing a watermark now uses less memory.

0.5.0

build 68 · 2026-10-15

Easy mode has one Add button and sorts your pictures itself. It asks only when unsure (is this the clean original? is this PNG a watermark file?) and Skip is always safe. Bursts of one scene count once, so they no longer blur the learned mark. Pictures of different sizes can be cleaned together when the watermark repeats. Send feedback from any screen. Hardware Test is in the ⋮ menu. No network use at startup; the self-test runs once per install.

0.2.13

build 67 · 2026-10-14 · first production release, live 2026-10-15

Easy mode guides photo selection, removal and manual refinement. Improved placement and preview handling reduces memory use. Results can show an estimate of the mark remaining, not a guarantee of clean output. Automatic pairing and saved-mark selection stay disabled where confidence is insufficient.

0.2.12

build 58 · 2026-10-01

Cleaner watermark removal from 3 or 4 photos: the stronger learner that used to need 5 or more photos now runs on any batch of 3 or more.

0.2.11

build 57 · 2026-09-30

Two-photo text watermarks are now removed by default and more cleanly, the app asks for 8-10 photos and learns from all of them for cleaner results with lower memory use, and colored stamps that were previously skipped are now removed.

0.2.10

build 56 · 2026-09-30

Two-photo text watermarks are now removed by default for much cleaner results with just 2 photos, and the app now asks for 8-10 photos and learns from all of them on the phone for cleaner results with lower memory use.

0.2.9

build 55 · 2026-09-26

Cleaner watermark removal: better results when learning from 5 or more photos, and repeated/tiled marks are now removed more accurately with less risk of false detections on plain photos.

0.2.8

build 54 · 2026-09-24

Better watermark removal when you learn from several photos: repeating marks such as tiled text are now removed much more cleanly, with no smudges copied from the picture. If the app can't find the same mark in your photos, it now says so and leaves them untouched instead of damaging them. Tip: learn from 5–8 photos for the best results.

0.2.7

build 53 · 2026-09-23

The privacy policy moved to our new website, scintech-dev.github.io. Nothing about what the app collects has changed.

0.2.6

build 52 · 2026-09-23

Learning a watermark now needs at least two photos that carry the same mark (or a clean original). For a single photo, the app sends you to Quick Remove, where you brush over the mark and it fills it in.

0.2.5

build 51 · 2026-09-23

Cleaner Workbench: tabs stay on top, the repeating-mark tick no longer disappears during Learn, and screens scroll all the way down. The daily self-check now pauses when you leave the app and resumes next time. Removal failures are reported (no photos included) so they can be fixed.

0.2.4

build 50 · 2026-09-22

Better diagnostics: reports now include memory and thermal state, why the app last stopped, and a marker when the daily self-check starts, so problems on your phone can be found and fixed faster. No photos or personal data are included.

0.2.3

build 49 · 2026-09-22

Hardware check results are now shared by default (turn off in Settings) and every report says which build it came from; the daily self-test no longer fails on lite builds.

0.2.2

build 48 · 2026-09-19

Daily self-check: once a day, on the first open, the app quietly verifies its own model and removal quality on two built-in sample photos (about 2–3 minutes on mid-range phones, runs in the background). Results contain no personal data and no photos; sharing them can be turned off in Settings.

0.2.0

build 46, 47 · 2026-09-19

First public beta! Watermark Remover clears repeated, tiled watermarks by learning the pattern from your photo itself — all on your device. The first analysis can take about a minute on mid-range phones. You can send an optional feedback report from Settings.

Seamless Video Looper

Seamless Video Looper releases

On Google Play as Seamless Video Looper: Offline. Current release: 1.10.0 (build 35). Notes below are the versioned en-US release notes kept in the app’s repository, unedited; exact release dates and build numbers are omitted where not recorded in the repository.

1.10.0

build 35

• Easy mode now also offers a longer loop: one of the results covers at least half of your clip, labeled "Longest loop". • New hint on the results screen: switch to Advanced mode in Settings to choose the loop length and where it cuts. • Long-clip warning now offers "Trim now". • Stability and crash-reporting fixes.

1.9.0

en-US release notes

• New "Our apps" screen in the menu: see the other SciNTech apps and open them on Google Play. • Fixed the privacy policy link in Settings so it opens the current page.

1.8.0

en-US release notes

• Save to gallery: one tap puts your loop in your Photos/Movies. • Large clips: when AI smoothing won't fit in memory, choose AI at a lower resolution or full resolution with a plain crossfade. Easy mode picks AI automatically. • Re-check RAM right from the memory warning. • Lower memory use for AI smoothing. • Result previews fit your clip's shape, with no black bars. • Easy mode spreads loop candidates across the whole clip. • Frame-accuracy and stability fixes.

1.7.10

en-US release notes

Fixes in this release: • Fixed Advanced mode exports that came out as a near-empty video. Re-export any Advanced loop made since version 1.7.6. • The smooth AI blend is now offered first more often in Easy mode. • Trim now explains what it is for: pick the part of the video to loop.

1.7.9

en-US release notes

Fixes in this release: • Better protection against running out of memory during renders on devices with less free memory. • More detailed error reports when the Hardware Test's motion analysis fails, so these issues can be fixed faster.

1.7.8

en-US release notes

Fixes in this release: • Fixed a crash when using the Back gesture or button between screens. • Videos now pause when you leave the app, even if they started playing just as you left. • Less memory pressure while you adjust the loop points, so renders are less likely to be interrupted. • More detailed crash reports, so native crashes can be diagnosed and fixed faster.

1.7.7

en-US release notes

Fixes in this release: • Smoother audio at the loop point: the sound now crossfades across the seam instead of jumping. • Renders no longer stall while you adjust the loop points on the Cut screen. • Leaving the app during the Hardware Test no longer turns off video enhancements. • Better motion effects on more phones with slower processors. • Videos stop playing in the background when you leave the app, saving battery.

1.7.6

en-US release notes

Fixes in this release: • Loop-point search on "Everywhere" no longer fails with an error on some long videos. • Canceling a render now stops it sooner, instead of finishing a background motion-analysis step first. • On slower phones, an unusually long motion-analysis step is now capped, so the render moves on with standard seam settings instead of waiting. • Behind the scenes: clearer error reports, so we can find and fix problems faster.

1.7.5

en-US release notes

Fixes in this release: • Large and 4K renders are less likely to be cut short on devices with limited memory. • A render that paused while your phone was asleep is no longer reported as a failure. • The feedback box no longer opens pre-filled with English technical text — just tell us what happened, in your own words. • Hardware Test now shows checks it deliberately skipped as "Skipped" rather than "Failed".

1.7.4

en-US release notes

Fixes a problem introduced by the last update. The change we made to AI motion analysis did not work as intended, and on some phones — including the Galaxy A54 — it stopped the GPU being used at all. Those phones now work the way they did before, and the hardware check runs once more after this update to pick that up. The rest of this release is behind-the-scenes reporting work, so we can tell different kinds of problem apart and fix them faster.

1.7.3

en-US release notes

The progress bar no longer freezes near the end of a render. On phones with newer Mali graphics (Pixel 8 and many Samsung, OnePlus and Nothing models), AI motion analysis now runs correctly on the GPU instead of being skipped. The hardware check runs once more after this update to pick it up. The memory safeguard now measures what the app is really using before a render, so it steps in when it should on phones with less RAM.

1.7.2

en-US release notes

The progress screen now keeps moving through the final stage instead of pausing at "Extracting frames". AI Interpolation now runs on more clips, so more loops get the smoothest seam.

1.7.1

en-US release notes

Fixed: on some phones with Imagination/PowerVR graphics (including Pixel 10/11 Pro), AI-smoothed loops could come out distorted or melted. Those devices now use a slower but correct path, so your loops look right. Also improved internal diagnostics so this class of problem is caught automatically in future.

1.7.0

en-US release notes

Smaller app, faster setup, easier feedback. • About 40 MB smaller to download and install. • Hardware Test finishes much faster — it now skips checks that wouldn't help your device, and marks them as skipped so you can see what it did. You can still run every check from Hardware Test. • Rate a finished loop right on the result card, with a tap. No need to share it first, and tapping the same star again won't clear your rating.

0.6.1

build 9

• Privacy screen is now a short summary with a link to the full policy on our website. • Clearer wording where you add calibration chart photos.
